# Agenda de Contactos CLI

## Descripción

Proyecto de consola desarrollado en Dart para gestionar una agenda telefónica básica.

## Funcionalidades

- Agregar contactos.
- Listar contactos.
- Buscar contactos.
- Eliminar contactos.

## Objetivo académico

Practicar programación en Dart, trabajo colaborativo y control de versiones mediante Git Flow.

## Estructura del proyecto

- `lib/`: código fuente de la aplicación.
- `lib/funciones/`: funciones para administrar los contactos.
- `bin/carloscastro/`: espacio destinado a los seis algoritmos del taller.

## Ejecución

Desde la raíz del proyecto, ejecutar:

```bash
dart run lib/main.dart
```

## Metodología

Se utilizarán las ramas `main`, `develop`, `feature` y `release`, junto con commits y Pull Requests en GitHub.
